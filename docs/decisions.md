| 런타임 감지에 `VAR=값` 접두·`env`/`command` 등 래퍼·서브셸 허용 | `NODE_OPTIONS= node x.js` 처럼 접두 하나만 붙이면 가드 전체를 건너뛰었다 (실제 사용 패턴) | 접두가 붙은 쓰기 스크립트도 deny |

## 2026-09-03

| 변경 | 왜 | 기대효과 |
|---|---|---|
| 세션 시작 훅 출력을 `systemMessage` JSON 으로 | 공식 문서: 이 이벤트는 평문 출력을 **모델 컨텍스트에 넣는다**. 주석의 "토큰 0"이 사실과 달랐다 | 매 세션 1.3KB 절약. 압축마다 재주입되던 것도 사라짐 |
| 훅 matcher 를 `startup\|resume` 으로 제한 | `*` 는 `compact`·`fork` 에도 걸렸다 | 압축마다 로그 회전이 다시 도는 낭비 제거 |
| CLAUDE.md 에서 규칙 색인 표 삭제 | 규칙은 이미 컨텍스트에 있다. 색인은 중복이고 갱신 누락 지점 | 이중 로드 제거, 유지 지점 1개 감소 |
| 산출물 골격을 `templates/` → `skills/` (`/plan`, `/bugfix`) | 공식 권고: 다단계 절차는 스킬로. "파일을 Read 하라"는 지시가 가장 약한 고리였다 | 본문이 호출 시에만 로드 → 상시 토큰 0. 모델이 상황에 맞춰 자동 호출 |
| 보안 경계를 권한 규칙에서 **sandbox** 로 | 공식 문서가 인자 제약 패턴은 취약하다고 명시. `python3 -c` 한 줄로 파일 차단이 뚫렸다 | 자격증명 읽기·외부 전송이 OS 레벨에서 차단. 자식 프로세스까지 적용 |
| `curl`·`claude`·`gh` 무제한 허용 제거 | 각각 데이터 외부 전송, 권한 우회 플래그, 원격 저장소 파괴 경로 | 우회 경로 3개 차단. 확인 프롬프트는 조금 늘어남 |
| 시크릿 마스킹을 **기록 시점** 으로 옮기고 4단 구성 | 파일에 평문으로 남았다. 헤더형·인라인형은 키 이름만 지워지고 값이 남았다 | 누출 형태 6종 차단. 로그 권한도 600 |
| db-guard 하드 차단을 "쓰기 SQL + 접속 코드 동시" 로 좁힘 | 주석에 `update the cache set` 이 있는 평범한 스크립트가 막혔다 | 오탐 제거 → 가드를 끄고 싶은 유혹이 사라짐. 단독 검출은 확인으로 한 단계 완화 |
| 상태라인에서 here-document 제거, `jq @sh` + `eval` | 임시 파일이 필요해 sandbox 에서 파싱이 통째로 실패. 소수점은 산술 오류로 스크립트를 죽였다 | 간헐적 소실 0. 셸 인젝션도 차단 |
| 두 퍼센트를 모두 **사용량** 기준으로 통일 | 컨텍스트는 잔여량, 사용 한도는 사용량이라 방향이 반대였다 | 두 숫자를 같은 방향으로 읽는다 |
| 서브에이전트 읽기 전용을 `disallowedTools` 로 | 프롬프트 약속만으로는 Bash 를 통해 실제로 쓸 수 있었다 | 하네스 레벨 보장. 선언이 아니라 강제 |
| `check.sh` 종료코드 전파 수정 | 파이프 때문에 테스트 실패가 삼켜졌다. **CI 가 항상 초록이었다** | 테스트 55건이 실제로 머지를 막는다 |
| `stat` 옵션 순서 반전, shellcheck 심각도 고정 | GNU `stat -f` 는 실패해도 stdout 을 오염시킨다. 분석기 버전 차이로 CI 만 빨갰다 | Linux CI 가 첫 실행부터 통과 |
| 링크 대상을 `*.sh` 글롭으로, 심링크 자동 복구 추가 | 과거 훅 하나가 목록에서 빠져 연결되지 않은 사고가 있었다 | 새 훅 추가 시 목록 수정 불필요. 빠진 링크는 세션 시작 때 자동 복구 |
| 이식성 검사 신설 (`check.sh` 9절) | macOS 에서만 검증해 Linux 전용 결함 2개를 놓쳤다 | 하드코딩 경로·bashism·폴백 없는 OS 전용 명령을 자동 차단 |
| 셸 이식성 규칙을 **경로 한정** 으로 분리 | 셸 파일에만 해당하는 규칙을 상시 로드할 이유가 없다 | `**/*.sh` 작업 시에만 로드 → 다른 작업의 컨텍스트 절약 |
| `origin/ft-home` 을 병합하지 않고 아이디어만 흡수 | 분기점이 오래돼 문서·상태라인이 충돌. 우리 구조가 더 진행돼 있었다 | 중복 도구 두 벌을 피하고 좋은 판단만 취함 |
